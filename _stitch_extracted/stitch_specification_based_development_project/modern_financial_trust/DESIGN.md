## Brand & Style

The design system establishes a high-precision, audit-ready financial management aesthetic rooted in clarity, security, and absolute reliability. Built for an enterprise-grade financial management platform, the visual language balances the weight of corporate finance with modern software ergonomics. It conveys technical authority, institutional competence, and transparent data presentation.

The design movement merges **Corporate / Modern** precision with **Minimalist** clarity:
- **Structural Integrity:** Crisp borders, strict alignment, and structured data tables take precedence over ornamental flourishes.
- **Cognitive Ease:** High contrast and deliberate negative space mitigate cognitive fatigue during long sessions involving multi-account reconciliation, auditing, and ledger analysis.
- **Accessible Verification:** Every critical metric, transaction status, and regulatory requirement provides immediate visual and programmatic clarity, adhering strictly to WCAG 2.1 AA benchmarks.

## Colors

The color system delivers high-contrast readability, clear data categorisation, and unambiguous semantic feedback. The default experience is calibrated for daylight enterprise productivity in **light mode**.

### Color Roles and Rules
- **Primary (`#0F172A`) & Deep Navy Slate (`#1E293B`):** Applied to core headings, primary action buttons, heavy navigational sidebars, and critical visual anchors. Evokes institutional safety and technical certainty.
- **Secondary (`#10B981`) & Deep Emerald (`#059669`):** Reserved strictly for financial accretion, income generation, net-positive variance, and verified transaction completion. It is paired with `#ECFDF5` for subtle background tagging.
- **Tertiary / Informational (`#0284C7`):** Powers active hyperlink interactions, informational stat callouts, audit metadata badges, and focus rings. Paired with `#F0F9FF`.
- **Neutrals (`#F8FAFC` to `#64748B`):** `#F8FAFC` defines the canvas surface, `#F1F5F9` hosts grouped panels and container cards, and `#CBD5E1` manages hairline data dividers. `#64748B` anchors secondary captions and field labels.
- **Semantic Status Signals:**
  - **Expense / Critical Alert (`#EF4444`):** Flags debits, balance deficits, security failures, and destructive operations. Never used as generic decoration.
  - **Warning / Due Notice (`#F59E0B`):** Alerts users to pending invoices, approaching maturity dates, or unverified ledger lines.
- **Accessibility & Compliance (WCAG 2.1 AA & FE-N.10):** Color is never the sole indicator of balance change or transactional state. Financial growth and debit indicators must always couple color with directional directional prefixes (`+`, `−`) and unambiguous iconography or textual indicators.

## Typography

Typography is calibrated for absolute numeric legibility, hierarchy clarity, and clean enterprise dashboards.

- **Display & Section Headers:** Set in **Plus Jakarta Sans** with tight tracking to project confidence and structural polish without sacrificing geometric discipline.
- **Body & Tabular Interface:** Set in **Inter** to ensure maximum legibility across complex forms, audit notes, and micro-copy.
- **Tabular Figures for Financial Numerical Accuracy:** All monetary amounts, ledgers, percentage changes, account balances, and table cells must enforce `font-feature-settings: "tnum" 1, "cv05" 1` (tabular figures and slashed zero). This ensures uniform vertical column alignment across rows regardless of individual digit widths, avoiding visual jitter during fast scanning.

## Layout & Spacing

The layout model is governed by an **8pt geometric spacing scale** (with a 4pt half-step for micro-insets and table cells), enforcing structured visual order.

### Grid & Breakpoint Model
- **Desktop (≥ 1280px):** 12-column fluid grid system bounded at a maximum container width of `1440px`. Column gutters are fixed at `1.5rem` (`24px`) with outer margins at `3rem` (`48px`). Side navigation docks to a fixed `280px` standard width.
- **Tablet (768px - 1279px):** 8-column layout with `1rem` (`16px`) gutters and `2rem` (`32px`) canvas margins. Navigation collapses to an expandable rail or header bar.
- **Mobile (320px - 767px):** 4-column layout with `1rem` (`16px`) margins and `0.75rem` (`12px`) gutters. Multi-column metric summaries stack vertically into sequential single-column stat cards.

### Dense Financial Rhythm
Data tables conform to a tight compact rhythm: `0.625rem` (`10px`) vertical cell padding and `0.875rem` (`14px`) horizontal cell clearance to maximize screen real estate during complex auditing workflows.

## Elevation & Depth

Visual hierarchy is communicated via **tonal layering and low-contrast perimeter borders** rather than pronounced drop shadows. This preserves an architectural, clean, and distraction-free visual environment suitable for high-density financial data.

- **Flat Canvas Foundation:** The application canvas rests on `#F8FAFC`. Base containers, operational cards, and table bodies render on crisp `#FFFFFF` panels.
- **Perimeter Definitions (Low-Contrast Outlines):** Surfaces achieve separation using a crisp 1px structural border of `#CBD5E1` (or `#E2E8F0` for interior subdivisions).
- **Subtle Ambient Shadows:** Where interactive elevation is necessary (e.g., dropdown menus, popovers, sticky headers, and modal overlays), apply restrained, cool-tinted ambient shadows:
  - *Layer 1 (Cards, Stat Containers):* `0 1px 2px 0 rgba(15, 23, 42, 0.04)` + `1px solid #CBD5E1`.
  - *Layer 2 (Dropdown Menus, Tooltips):* `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)` + `1px solid #CBD5E1`.
  - *Layer 3 (Modals, Slide-over Drawers):* `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`. Modals use a backdrop scrim of `#0F172A` at 45% opacity with a `4px` blur.

## Shapes

The design system employs a **Soft (`1`)** shape language. Tight, conservative corners maintain an authoritative financial posture without feeling sterile or antiquated.

- **Interactive Controls & Inputs:** Form fields, select dropdowns, and buttons use a disciplined `0.25rem` (`4px`) corner radius (`rounded`).
- **Cards & Data Modules:** Standard metric containers, stat cards, and data table envelopes use `0.5rem` (`8px`) corner radius (`rounded-lg`).
- **Pills & Status Chips:** Financial status chips and transaction verification tags use `0.25rem` (`4px`) to preserve structural alignment with nearby tabular numerals, avoiding overly playful circular pill containers.

## Components

### Buttons & Interactive Triggers
- **Primary:** Background `#0F172A`, text `#FFFFFF`, border `1px solid #0F172A`. On hover: `#1E293B`. Active: `#020617`. Focus ring: `2px` offset with `2px solid #0284C7`.
- **Secondary / Ghost:** Background `#FFFFFF`, text `#1E293B`, border `1px solid #CBD5E1`. On hover: `#F1F5F9`.
- **Growth / Positive Action:** Background `#10B981`, text `#FFFFFF`. Hover: `#059669`.
- **Destructive:** Background `#EF4444`, text `#FFFFFF`. Hover: `#DC2626`.

### Stat Cards & Metric Tiles
- Surface `#FFFFFF` enclosed in `1px solid #CBD5E1` with `0.5rem` corner radius.
- Includes a subtle label (`label-sm`, `#64748B`), an oversized currency figure (`currency-stat`, `#0F172A`) featuring tabular numbers, and a bottom metadata trend indicator.
- Positive trends render with `#ECFDF5` fill, `#059669` text, an upward chevron `▲`, and `+` prefix. Negative trends render `#FEF2F2` fill, `#EF4444` text, downward chevron `▼`, and `−` prefix.

### Data Tables & Financial Ledgers
- Outer container framed with `1px solid #CBD5E1` and `rounded-lg` wrapper corners.
- Header row styled with `#E2E8F0` fill, `#1E293B` uppercase tracking labels (`label-sm`), and a bottom border `1px solid #CBD5E1`.
- Rows alternate or hover with `#F8FAFC`. Cells enforce tabular figures right-aligned for monetary balances, left-aligned for transaction descriptions, and centered for transaction tags.

### Status Chips & Badges
- **Settled / Verified:** `#ECFDF5` background, `#059669` text, `1px solid #A7F3D0` border.
- **Pending / Due:** `#FFFBEB` background, `#D97706` text, `1px solid #FDE68A` border.
- **Failed / Overdrawn:** `#FEF2F2` background, `#DC2626` text, `1px solid #FECACA` border.
- **System Info / Audit:** `#F0F9FF` background, `#0284C7` text, `1px solid #BAE6FD` border.

### Form Controls & Financial Inputs
- Field backgrounds set to `#FFFFFF` with `1px solid #CBD5E1` borders, standardizing on a `40px` height rhythm.
- Monetary amount inputs feature an integrated leading currency unit anchor (e.g., `USD $`) styled with `#64748B` on `#F1F5F9` background, separated by a vertical border.
- Focused inputs illuminate with `border-color: #0284C7` and an accessible `box-shadow: 0 0 0 3px rgba(2, 132, 199, 0.15)`.

### Alert Banners
- Horizontal rectangular alerts with `0.25rem` radius, 1px perimeter border, and a left highlight strip of `4px` width matching the semantic token (`#EF4444`, `#F59E0B`, `#0284C7`, `#10B981`).
- Banners include semantic iconography aligned with the heading to fulfill non-color-only cues under WCAG 2.1 AA (FE-N.8).
