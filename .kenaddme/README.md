# KenAddme IT Links project governance

This directory was initialized from the approved KenAddme IT Links frameworks.

- Project class: Class A
- Software class: Class 3
- Frameworks become fully mandatory on 31 October 2026.
- The authoritative decision is the recorded gate decision, not checklist completion.

Begin with the Gate 1 / G0 intake evidence. Keep owners, approvals, evidence references,
risks, decisions, changes, releases and exceptions in controlled records. Do not commit
secrets or restricted data to this directory.

The copied tracker API is a reference implementation. Before exposing it, mount it into
the application using the application's authentication and authorization dependencies.
